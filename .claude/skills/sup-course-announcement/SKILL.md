# SUP 강사·지도자 과정 교육공지 작성

KSUPA(대한패들보드연맹)가 새 회차 SUP 지도자 과정을 모집할 때, **네이버 카페·블로그에 바로 붙여넣을 수 있는 공지글**을 만드는 스킬입니다. 매 회차 바뀌는 건 몇 가지뿐(차수·날짜·장소)이고 나머지는 늘 같기 때문에, 고정 정보를 자동으로 채워 매번 일관된 톤과 구성을 유지하는 것이 핵심입니다.

## 산출물 두 가지

이 스킬은 목적에 따라 두 형태를 만듭니다. 사용자가 어느 쪽인지 애매하면 둘 다 만들어 주는 게 안전합니다.

- **텍스트 공지글** — 네이버 카페·블로그·단톡방에 붙여넣는 글. (아래 "출력 형식" 참고)
- **게시판용 HTML** — 우리 홈페이지 게시판/페이지에 올리는, 홈페이지 디자인(오션 블루·틸)에 맞춘 카드형 공지. (아래 "게시판 HTML 만들기" 참고)

"홈페이지에 올릴", "게시판 공지", "HTML로", "카드로 예쁘게" 같은 말이 나오면 HTML을 만듭니다.

## 작업 순서

1. **고정 정보 로드** — `references/ksupa-info.md`를 읽습니다. 기관소개·표준 시간표·준비물·교육비·계좌·문의처·슬로건이 들어 있습니다. 이 값들은 사용자가 다르게 말하지 않는 한 그대로 씁니다.
2. **회차 정보 확보** — 아래 "받아야 할 정보"를 사용자 메시지에서 뽑아냅니다. 빠진 필수 항목이 있으면 추측하지 말고 짧게 되물어 확인합니다.
3. **형식/산출물 선택** — 텍스트(상세형·간단형) / HTML 중 무엇을 만들지 정합니다. 텍스트는 지정이 없으면 **상세형**, "간단하게/짧게"면 간단형.
4. **작성** — 텍스트면 아래 템플릿대로, HTML이면 "게시판 HTML 만들기"의 스크립트로 생성합니다.
5. **전달** — 텍스트는 코드블록으로 감싸 복사 가능하게, HTML은 파일로 저장해 경로를 알려 주고 미리보기를 보여 줍니다. 바뀔 만한 값(연락처·교육비 등)은 한 줄로 확인 요청을 덧붙입니다.

## 작성 규칙

- **사실을 지어내지 않는다.** 준비물·교육비·계좌·시간표는 `references/ksupa-info.md`에 있는 값만 씁니다. 사용자가 주지 않은 정원·강사명·환불조건 등은 임의로 넣지 말고, 필요하면 되묻습니다.
- **연락처·계좌는 민감 정보**입니다. 기본값을 쓰되, 담당자가 바뀌었을 수 있으니 마지막에 "연락처·계좌 그대로 쓸까요?" 정도로 가볍게 확인합니다.
- **날짜 표기**는 사용자가 준 형식을 존중하되, 요일이 빠졌으면 넣어 주면 좋습니다(예: 8/17 → 8월 17일(월)). 요일을 스스로 계산해 넣었다면 그 사실을 한 줄로 알려 사용자가 검증하게 합니다.
- **레벨 표기**: 포스터에서는 "SUP 레벨1", "SUP 지도자 레벨1 과정" 두 가지로 쓰입니다. 사용자 표현을 따르되 제목과 본문에서 일관되게 씁니다.
- **톤**: 신뢰감 있고 명료하게. 과장 광고 문구나 이모지 남발은 피합니다. KSUPA는 문체부 등록 민간자격 기관이라는 점이 신뢰의 핵심입니다.
- 완성글은 **코드블록으로 감싸** 사용자가 통째로 복사할 수 있게 합니다.

**출력:** 상세형 템플릿에 차수=제49차, 과정명=SUP 지도자 레벨1 과정, 일정=2026년 9월 21일(일) 09:00~18:00, 장소=뚝섬 윈드서핑장 44호 (카이트존스포츠), 접수 상태=신청 접수중 을 채워 완성글을 코드블록으로 제시. 끝에 "연락처·계좌는 기존 그대로 넣었어요. 바뀐 게 있으면 알려주세요." 한 줄 확인.

## 게시판 HTML 만들기

홈페이지 게시판/페이지용 카드형 공지 HTML은 `scripts/build_announcement.py`로 생성합니다. 고정 정보(시간표·교육비·계좌·문의처·슬로건)는 `assets/announcement-template.html`에 이미 들어 있으므로, **회차마다 바뀌는 값만 인자로 넘기면** 됩니다. 매번 HTML을 직접 손으로 쓰지 말고 이 스크립트를 쓰세요 — 결과가 항상 같은 디자인으로 나오고, 실수로 계좌·연락처를 틀리게 옮길 일이 없습니다.

```bash
python3 .claude/skills/sup-course-announcement/scripts/build_announcement.py \
  --chasu "제49차" \
  --course "SUP 지도자 레벨1 과정" \
  --date "2026년 9월 21일(일) 09:00~18:00" \
  --venue "뚝섬 윈드서핑장 44호 (카이트존스포츠)" \
  --status "신청 접수중" \
  --out notices/49th-level1.html
```

- `--format` 으로 산출 형태를 고릅니다. 이게 핵심입니다:
  - `page` (기본) — `<style>`·외부폰트를 포함한 **완결형 HTML 파일**. 브라우저로 바로 열리고, 저장소 페이지로 커밋하거나 iframe으로 넣기 좋습니다.
  - `fragment` — `<style>` 없이 **모든 스타일을 요소에 인라인으로 박은 조각**. 게시판 글쓰기의 `HTML`/`소스코드` 모드에 붙여넣어도 디자인이 안 깨집니다. 그누보드·워드프레스·아임웹·카페24 등 자체 홈페이지 게시판용은 **거의 항상 `fragment`** 를 씁니다.
- `--status` 는 생략 시 "신청 접수중". 값에 **임박/마감/연기/완료** 가 들어가면 배지 색이 자동으로 바뀝니다(접수중=청록, 임박=주황, 마감·연기·완료=회색).
- `--notice "문구"` 를 붙이면 "안내사항" 항목이 추가됩니다(여러 번 사용 가능). 없으면 항목 자체가 안 나옵니다.
- `--out` 을 생략하면 HTML이 표준출력으로 나옵니다.

**어느 형식을 줄지 판단:** 사용자가 "게시판에 붙여넣을", "글쓰기 HTML 모드", "코드로 올릴" 이라고 하면 `fragment`. "페이지로", "사이트에 걸", "파일로" 면 `page`. 애매하면 둘 다 만들어 주고 차이를 한 줄로 설명하세요. `fragment` 는 `announcement-fragment.html`, `page` 는 `announcement-template.html` 을 씁니다 — 고정 정보를 바꿀 땐 두 템플릿을 함께 고쳐야 합니다.

만든 뒤에는 결과 HTML을 브라우저로 렌더링해 한 번 눈으로 확인하고(가능하면 스크린샷), 사용자에게 파일 경로와 미리보기를 함께 전달하세요. 완성 파일은 자체 완결형(self-contained)이라 게시판 HTML 입력란에 붙여넣거나 저장소 페이지로 커밋해 바로 쓸 수 있습니다.

### 고정 정보를 바꿔야 할 때

계좌·연락처·교육비·시간표가 실제로 바뀌면 **두 곳을 같이** 고쳐야 일관성이 유지됩니다: `references/ksupa-info.md`(텍스트 공지용 원본)와 `assets/announcement-template.html`(HTML용). 한 쪽만 고치면 텍스트와 HTML이 어긋납니다.

## 참고

포스터(정사각형 이미지 등)까지 필요하면 위 HTML 카드를 이미지로 캡처하거나, 강사과정 페이지 스타일에 맞춰 별도 포스터를 만들 수 있습니다. 다만 이 스킬의 기본 산출물은 **붙여넣기용 공지 글**과 **게시판용 HTML**입니다.
