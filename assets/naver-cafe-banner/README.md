# SSUMSS 네이버 카페 좌측 메뉴 광고배너

`ssumss___.ai` 로고를 바탕으로 만든, 네이버 카페 **좌측 메뉴란**용 광고배너입니다.

## 사이즈

네이버 카페 좌측 메뉴 영역은 **가로 170px 고정**입니다. (네이버 위젯/메뉴 배너 공통 규격)
그래서 배너를 **170px 폭**에 맞춰 제작했습니다.

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `ssumss-menu-light-170.png` | 170 × 100 | 화이트(기본, 로고 컬러 BLACK 반영) — 실제 업로드용 |
| `ssumss-menu-light-340.png` | 340 × 200 | 화이트 2배 고해상도(레티나) |
| `ssumss-menu-dark-170.png`  | 170 × 100 | 다크(흰 카페 배경에서 눈에 잘 띔) — 실제 업로드용 |
| `ssumss-menu-dark-340.png`  | 340 × 200 | 다크 2배 고해상도 |

> 카페에 실제로 올릴 때는 **170px 폭 파일**을 사용하세요. 2배(340px) 파일은 고해상도 화면 대비용 원본입니다.

## 네이버 카페에 넣는 방법

1. 카페 관리 → **꾸미기 → 메뉴(좌측 메뉴) 관리**로 이동합니다.
2. 배너/이미지를 넣을 수 있는 영역(예: 메뉴 상·하단, 대표 이미지)에서 위 PNG를 업로드합니다.
   - 에디터에 이미지 삽입이 되는 경우: 이미지를 넣고 **가로 170**으로 맞춥니다.
   - HTML/위젯 형태로 넣는 경우 아래 코드를 사용하세요.
3. 배너에 링크(브랜드 스토어/상품 페이지)를 연결합니다.

```html
<a href="여기에_링크_주소" target="_blank">
  <img src="업로드된_이미지_주소" width="170" alt="SSUMSS" style="display:block;border:0;">
</a>
```

## 수정하기

`banner-source.html`을 브라우저로 열면 화이트/다크 두 버전이 그대로 보입니다.
- 하단 `바로가기` 문구, 색상, 자간 등은 이 파일의 CSS에서 바로 고칠 수 있습니다.
- 폰트는 로고와 가장 비슷한 기하학적 씬(thin) 산세리프 **Jost** (SIL OFL 1.1)를 base64로 내장했습니다.
- 문구/링크를 알려주시면 그대로 반영해 다시 뽑아 드립니다.
