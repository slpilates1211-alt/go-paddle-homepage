## 1/5. 연혁(활동내역) 업데이트 스킬  · 출력=(B) 페이지용

```
[스킬 1/5] 연혁 업데이트 스킬을 만들어줘.
- 이름: ksupa-history-update
- 역할: 새 활동을 연·월·카테고리로 입력하면 history.html 타임라인에 반영.
- 입력 예: "2026년 8월 | 교육 | 제49기 SUP 국제강사 레벨1 과정 in 서울 | 강조"
- 규칙(기존 history.html 구조/색상 그대로):
  · 해당 연도 섹션에 시간순 삽입. 같은 월 연속 중복 시 첫 항목만 월 표시, 나머지 빈칸.
  · 카테고리 색상 클래스 자동: 교육=cat-edu, 대회·이벤트=cat-event, 조직·설립=cat-org,
    협약·제휴=cat-partner, 출판·미디어=cat-media, 학술·강연=cat-academic, 수상=cat-award.
  · '강조' 입력 시 ks-star.
- 출력형식: (B) 페이지용 — 기존 history.html 방식(<style> 포함) 유지. TOP 버튼도 유지.
- 완성 후 테스트하고 .skill로 패키징.
```

## 2/5. 게시판 공지·안내 카드 스킬  · 출력=(A) 게시판용 ★규칙 엄수

```
[스킬 2/5] 게시판 공지·안내 카드 스킬을 만들어줘.
- 이름: ksupa-board-notice
- 역할: 아임웹/네이버 게시글에 붙여넣는 브랜드 공지 카드 생성.
- 유형: 환영글 / 이벤트·행사 / 휴무·휴강 / 필독 공지 / 후기 요청 등.
- 입력: 유형, 제목, 본문, (선택) 버튼 문구+링크.
- ★출력형식: (A) 게시판용 안전 규칙 엄수 — <table> 레이아웃, 단색 background-color만,
  HTML 주석 금지, clamp/gap/<style>/<script> 금지, 전부 인라인, font-weight:bold,
  max-width:640px 유동폭. (참고 검증본: notices/48th-level1-board.html)
- 구성: 남색 헤더 + 본문 + (선택) 레드 CTA 버튼 + 서명("— KSUPA 운영진 드림").
- 출력: 붙여넣기용 HTML + 미리보기. 완성 후 테스트하고 .skill로 패키징.
```
