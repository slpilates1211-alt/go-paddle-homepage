## 1/5. 연혁(활동내역) 업데이트 스킬

```
[스킬 1/5] 연혁 업데이트 스킬을 만들어줘.
- 이름: ksupa-history-update
- 역할: 새 활동을 연·월·카테고리로 입력하면 history.html 타임라인에 반영.
- 입력 예: "2026년 8월 | 교육 | 제49기 SUP 국제강사 레벨1 과정 in 서울 | 강조"
- 규칙(기존 history.html 구조/색상 그대로 준수):
  · 해당 연도 섹션에 시간순 삽입. 같은 월이 연속 중복되면 첫 항목만 월 표시, 나머지는 빈칸.
  · 카테고리 색상 클래스 자동: 교육=cat-edu, 대회·이벤트=cat-event, 조직·설립=cat-org,
    협약·제휴=cat-partner, 출판·미디어=cat-media, 학술·강연=cat-academic, 수상=cat-award
    (반투명 배경 + 진한 동색 글씨).
  · '강조' 입력 시 ks-star 클래스 부여.
- 출력: 갱신된 history.html 전체 + 추가·변경 부분 미리보기.
- 완성 후 테스트하고 .skill로 패키징.
```

## 2/5. 게시판 공지·안내 카드 스킬

```
[스킬 2/5] 게시판 공지·안내 카드 스킬을 만들어줘.
- 이름: ksupa-board-notice
- 역할: 게시판(아임웹/네이버) HTML 모드에 붙여넣는 브랜드 공지 카드 생성. board-welcome.html 패턴.
- 지원 유형: 환영글 / 이벤트·행사 안내 / 휴무·휴강 / 필독 공지 / 후기 요청 등.
- 입력: 유형, 제목, 본문, (선택) 버튼 문구+링크.
- 규칙: 전부 인라인 스타일(<style>·<script> 금지). 상단 그라데이션 헤더 + 본문 +
  (선택) 레드 CTA 버튼 + 서명("— KSUPA 운영진 드림"). 브랜드 팔레트 준수.
- 출력: 붙여넣기용 인라인 HTML + 미리보기.
- 완성 후 테스트하고 .skill로 패키징.
```

## 3/5. 홍보 배너·이미지 스킬

```
[스킬 3/5] 홍보 배너·이미지 스킬을 만들어줘.
- 이름: ksupa-promo-banner
- 역할: 채널 규격별 브랜드 배너를 HTML로 만들고 PNG로 내보내기(Playwright 렌더 → PNG).
- 규격 내장: 네이버 카페 좌측메뉴 170px폭, 카페 타이틀 957px폭, 인스타 1080×1080,
  홈페이지 히어로(와이드) 등. (사용자가 채널만 말하면 규격 자동 선택)
- 입력: 채널/규격, 문구(회차·행사명·CTA).
- 규칙: 브랜드 팔레트. 가격·핵심 숫자는 레드, 나머지는 블루. 한글 폰트 렌더 확인.
- 출력: 규격에 맞는 PNG + 소스 HTML.
- 완성 후 테스트하고 .skill로 패키징.
```

```
[스킬 4/5] 홈페이지 섹션/랜딩 블록 스킬을 만들어줘.

- 출력: 섹션 HTML + PC/모바일 미리보기.
```
